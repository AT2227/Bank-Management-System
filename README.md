# Bank Management System

A Java desktop application developed using Object-Oriented Programming (OOP) and Java Swing.

## Features
- Account management
- Deposit & Withdraw
- Money Transfer
- Transaction History
- Employee Login
- File-based data storage

## Technologies
- Java
- Java Swing
- NetBeans
- File Handling

> This project was originally developed as a Programming II university final project and is being continuously improved to apply modern software engineering practices.
